# 🧪 Lab-Mate — AI Protocol Auditor

AI-powered web app auditing biotechnology lab protocols 
for university students.

## 🚀 Live Demo
👉 [Live on Hugging Face](https://huggingface.co/spaces/aqibmasood3/Lab-Mate)

## ⚙️ Tech Stack
- **AI:** Groq API (Llama 3.3-70B)
- **Backend:** FastAPI + Python
- **Frontend:** React.js
- **Deployment:** Hugging Face Spaces

## ✨ Features
- Audits PCR, DNA Extraction, Gel Electrophoresis protocols
- 3-layer document validation
- Detects Critical Failure Points & safety hazards
- Drag & drop PDF/DOCX upload
